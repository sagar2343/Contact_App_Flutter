# Contacts App

A Flutter-based Contacts Management application developed as part of an interview assignment.

## Overview

Contacts App is a simple and intuitive contact management application that allows users to store and manage their contacts locally using SQLite. The application provides essential contact management functionality with a clean Material Design interface.

## Features

### Contact Management

* Add new contacts
* View all contacts
* Edit existing contacts
* Delete contacts with confirmation
* Search contacts by name

### Favorites

* Mark contacts as favorites
* View favorite contacts separately
* Remove contacts from favorites

### Contact Details

* View detailed contact information
* Direct call functionality
* Edit contact information
* Delete contact

### Local Storage

* SQLite database integration
* Offline functionality
* Persistent data storage

## Tech Stack

* Flutter
* Dart
* SQLite (sqflite)
* Provider (or your state management)
* Material Design 3
* url_launcher

## Installation

### Prerequisites

* Flutter SDK
* Android Studio or VS Code
* Android Emulator or Physical Device

### Steps

1. Clone repository

```bash
git clone <repository-url>
```

2. Navigate to project

```bash
cd contacts_app
```

3. Install dependencies

```bash
flutter pub get
```

4. Run application

```bash
flutter run
```
